# ✨ DataMind AI – Data Analyst Dashboard

A responsive, browser-based data analytics dashboard built using HTML, CSS and JavaScript. It helps users upload supported data files, explore numerical statistics, check basic data quality and visualize information through interactive charts.

## 🚀 Features

- Login and registration demo interface
- Responsive desktop and mobile layout
- CSV, Excel, text and text-based PDF file uploads
- Automatic detection of numeric columns
- Basic data-quality checks and cleaning
- Sales, average, median, net amount and trend calculations
- Interactive bar, line, doughnut and radar charts
- Custom chart color palettes and legend controls
- Dark and light theme
- Sample data for testing
- Browser-based storage for demo accounts and recent data

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- SheetJS (XLSX)
- PDF.js
- Browser LocalStorage

## ▶️ How to Run Locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Register a demo account.
4. Upload a supported file or click **Try sample data**.
5. Explore the dashboard and customize the charts.

## ⚠️ Limitations

This is a front-end demonstration project. Login credentials and dashboard data are stored in browser storage and are not protected by a real authentication backend. Do not use real passwords or sensitive business data.

The current version does not implement a Gemini API integration or a backend-based AI service.
